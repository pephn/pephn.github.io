1Introducció

Què és un SGE?

Un Sistema de Gestió Empresarial (SGE) és un conjunt d'aplicacions que centralitza i automatitza els processos d'una organització (comptabilitat, vendes, compres, magatzem, producció, recursos humans, relació amb clients...) en una única base de dades compartida. Així, tots els departaments treballen amb la mateixa informació en temps real, s'eviten duplicitats i es pot prendre decisions amb dades fiables.

ERP

Enterprise Resource Planning. Gestiona els recursos i processos interns: finances, inventari, compres, producció, projectes.

CRM

Customer Relationship Management. Gestiona la relació amb clients: oportunitats, campanyes, casos de suport.

BI

Business Intelligence. Analitza les dades de l'empresa mitjançant informes, quadres de comandament i previsions.

L'SGE escollit: Acumatica Cloud ERP

Acumatica és un ERP «nascut al núvol» (cloud-native) dirigit a petites i mitjanes empreses (pimes). Ofereix una suite integrada amb finances, distribució, fabricació, construcció, comerç minorista, serveis professionals, servei de camp i CRM, sobre una plataforma pròpia basada en tecnologia Microsoft (C#, ASP.NET i SQL Server).

Es correspon amb el tipus ERP, tot i que incorpora un mòdul de CRM natiu i eines de BI (consultes genèriques, quadres de comandament i informes), de manera que cobreix part de les tres categories.

2Informació general del sistema

2.1 Desenvolupador i història cronològica

Acumatica és desenvolupat i comercialitzat per Acumatica, Inc., una empresa nord-americana amb seu a Bellevue (Washington, EUA) (algunes fonts antigues la situen a Kirkland, a la mateixa àrea metropolitana de Seattle). Té oficines a Amèrica del Nord, Europa i Àsia, i comercialitza el producte a través d'una xarxa de partners (VAR) i desenvolupadors independents (ISV).

  • 2008: es presenta el producte Acumatica ERP, una de les primeres suites de gestió empresarial pensades per al núvol i accessibles des del navegador.
  • 2009: apareixen les modalitats on-premise i SaaS. Acumatica va ser també un dels primers ERP comercials disponibles a Microsoft Azure.
  • 2014: Jon Roskill (exvicepresident de Microsoft) esdevé CEO i es llança la plataforma xRP, que permet construir aplicacions de negoci sobre el mateix framework.
  • 2017-2021: premis com PC Magazine Editors' Choice (millor programari ERP, 2017), CODiE Award a millor ERP al núvol (2018) i a millor ERP (2021). El 2021 també apareix al quadrant de Gartner de Cloud ERP.
  • 2019: el fons d'inversió EQT hi fa una inversió que impulsa el creixement internacional.
  • 29 de maig de 2025: s'anuncia l'adquisició d'Acumatica per part de Vista Equity Partners, venuda per EQT VII (tancament previst pel tercer trimestre de 2025). Els mitjans xifren l'operació en uns 2.000 M$ incloent-hi el deute.
  • Març de 2026: llançament de la versió 2026 R1, amb millores de IA, serveis professionals, construcció i cadena de subministrament.

2.3 Llenguatges de programació

  • C# sobre .NET i ASP.NET: llenguatge principal de la plataforma i de les personalitzacions.
  • SQL / T-SQL: accés a dades i scripts de personalització.
  • HTML, CSS i JavaScript: interfície web i personalitzacions del client.
  • BQL (Business Query Language): llenguatge propi per escriure consultes que el framework tradueix a SQL.

2.4 Plataformes compatibles

Servidor

Windows Server (64 bits) amb IIS. Per a producció cal un sistema operatiu de servidor; Windows 10/11 només per a proves. No hi ha servidor oficial per a Linux o macOS.

Client

Qualsevol sistema amb un navegador modern: Windows, macOS, Linux, Chrome, Edge, Firefox i Safari.

Mòbil

Aplicació mòbil per a iOS i Android, molt utilitzada en servei de camp, despeses i aprovacions.

2.5 Arquitectura del programari

Acumatica utilitza una arquitectura web multicapa client-servidor. El navegador (o l'app mòbil) es comunica amb un servidor web IIS que executa l'aplicació ASP.NET; aquesta aplicació es basa en el Acumatica Framework (xRP), que organitza el codi en classes d'accés a dades (DAC) i controladors de lògica de negoci (BLC o Graph), i es comunica amb la base de dades relacional. A més, exposa una API REST i SOAP per a integracions.

2.6 Altres dades rellevants

  • Multiempresa, multidivisa i multientitat: gestió de diverses societats i monedes dins la mateixa instància.
  • Multitenant a la versió al núvol.
  • Marketplace amb aplicacions de tercers (uns 300 ISV segons fonts externes).
  • Edicions per sector: distribució, fabricació, construcció, comerç minorista, serveis professionals, servei de camp...
  • Propietat actual: Vista Equity Partners (des del 2025).

3Tipus de llicències i preus

3.1 Tipus de llicència

Acumatica és programari comercial i propietari (no és programari lliure ni gratuït). Ofereix una versió de prova i entorns de demostració, però no una edició gratuïta. La seva característica diferencial és el llicenciament per consum de recursos: no es cobra per usuari, de manera que es poden afegir usuaris il·limitats (empleats, clients, proveïdors) sense cost addicional per llicència.

3.2 Modalitats de distribució

ModalitatDescripció
SaaS (Acumatica Cloud)Hosting gestionat per Acumatica als seus servidors al núvol (a Amazon Web Services). Segons fonts de partners, és la modalitat de l'ordre del 85 % de les implantacions.
Private Cloud / IaaSEl client (o un partner) allotja la instància en un núvol propi (Azure, AWS...).
On-PremiseInstal·lació als servidors del client; llicència de subscripció o, històricament, de llicència perpètua.

3.3 Modalitats de subscripció i preus

  • Subscripció anual basada en tres factors: aplicacions/edicions contractades, nivell de consum de recursos (volum de transaccions, emmagatzematge i potència de càlcul) i modalitat de desplegament.
  • Venda indirecta: els preus els proporcionen els partners (VAR) mitjançant pressupost; Acumatica no publica preus al seu web.
  • Evolució del model: abans d'abril de 2018 es llicenciava per nuclis lògics de CPU; després va passar a nivells de transaccions i posteriorment es va simplificar el model.
  • Ordre de magnitud (orientatiu, font de tercers): d'uns 10.000 a 80.000 USD/any de llicència segons l'empresa, o d'uns 1.500 a 3.000 USD/mes. A això cal afegir-hi el cost d'implantació, que pot ser molt superior a la llicència.
Nota: els imports són estimacions de portals externs i partners, no preus oficials. Per al treball cal indicar-ho així i, si es pot, demanar un pressupost real a un partner.

4Sistemes gestors de bases de dades associats

Microsoft SQL Server

És el SGBD principal i el més utilitzat amb Acumatica (també a la versió SaaS). Base de dades relacional, amb llenguatge T-SQL. Permet la cerca semàntica i full-text si s'instal·la aquesta característica.

MySQL Community Edition

Alternativa de codi obert també relacional, compatible per a instal·lacions on-premise. Redueix el cost de llicències de base de dades.

Altres informacions rellevants

  • Tipus de SGBD: relacional (SQL). No s'utilitza una base de dades documental com a magatzem principal.
  • Accés a les dades: el framework mapeja cada taula a una classe DAC, i les consultes s'escriuen en BQL, que es tradueix a SQL pel motor.
  • Integració i BI: API REST/SOAP, OData per a eines com Excel o Power BI i connectors ADO.NET de tercers.
  • Requisits de servidor (on-premise): Windows Server de 64 bits, IIS, i versions recents de SQL Server (consulteu la documentació de cada release, ja que canvien cada any).

5Instal·lació i accés al sistema

5.1 Tipus d'instal·ladors

Acumatica ERP Installer

Instal·lador per a Windows que desplega el servidor web i l'Acumatica ERP Configuration Wizard.

Configuration Wizard

Assistent per crear i configurar instàncies: connexió al SGBD, creació de la base de dades i dades de demostració.

Acumatica Framework + plantilles

Per a desenvolupadors: plantilles de Visual Studio per crear aplicacions sobre el framework.

5.2 Procés d'instal·lació (on-premise)

  1. Comprovar requisits: Windows Server de 64 bits (o Windows 10/11 per a proves), 16 GB de RAM recomanats i IIS activat amb les funcions necessàries.
  2. Instal·lar SQL Server (o MySQL) i configurar permisos i l'accés per xarxa.
  3. Descarregar i executar l'Acumatica ERP Installer des del portal de la comunitat.
  4. Executar l'assistent de configuració: triar el servidor de BD, el directori, el nom de la instància i les dades de demostració.
  5. Activar HTTPS amb un certificat (obligatori per a funcions com SSO i exportació a Excel).
  6. Accedir pel navegador a la URL de la instància i iniciar sessió amb l'usuari administrador.

5.3 Procés de contractació (SaaS)

  1. Contactar amb un partner autoritzat (VAR) o demanar una demostració a Acumatica.
  2. Anàlisi de necessitats: edicions, aplicacions i volum de transaccions.
  3. Pressupost de subscripció i signatura del contracte.
  4. Acumatica proporciona l'entorn al núvol i el partner fa la implantació i la formació.

5.4 Modalitats d'accés

🌐 Web

Accés principal des del navegador, sense instal·lar res al client.

📱 App mòbil

Aplicació per a iOS i Android per a aprovacions, despeses, servei de camp i consulta de dades.

🔌 API

Accés programàtic via REST/SOAP/OData per a integracions amb altres programes.

No existeix un «client d'escriptori» tradicional: tot el sistema s'executa en un navegador.

6Mòduls i funcionalitats

6.1 Els tres mòduls més importants

💶 Gestió financera

És el nucli del sistema. Inclou llibre major, comptes a pagar i a cobrar, tresoreria, conciliació bancària, actius fixos, pressupostos, multidivisa i consolidació multiempresa. Totes les operacions dels altres mòduls generen assentaments comptables automàtics.

📦 Gestió de la distribució

Cobreix compres, vendes, inventari multimagatzem, ordres de venda i de compra, lots i números de sèrie, preus i descomptes, i enviaments. Permet controlar l'estoc en temps real des de qualsevol dispositiu.

🤝 CRM

Gestiona clients potencials, oportunitats, pressupostos, campanyes de màrqueting, casos de suport i el flux d'activitats. Comparteix la mateixa base de dades que l'ERP, de manera que el comercial veu el crèdit, l'estoc i les factures del client.

Altres aplicacions rellevants: fabricació, comptabilitat de projectes, construcció, comerç electrònic i retail, servei de camp, nòmines, despeses i informes i tauler (dashboards). La versió 2026 R1 ha incorporat millores d'IA i flux de treball sense codi.

6.2 Capacitat de crear nous mòduls

Acumatica està pensat per ser ampliat. Les extensions es publiquen com a projectes de personalització (Customization Projects), que es poden aplicar o revertir sense modificar el codi original: el framework crea fitxers C# addicionals per estendre les classes.

Llenguatges i tecnologies

  • C# / .NET per a la lògica de negoci i les extensions.
  • ASPX, HTML i JavaScript per a l'aspecte de les pantalles.
  • SQL per a esquemes i scripts de base de dades.
  • Eines sense codi / amb poc codi: editor de pantalles, consultes genèriques (Generic Inquiries), dissenyador d'informes i motor de fluxos de treball.
  • APIs REST/SOAP per integrar sistemes externs.

Eines de desenvolupament (IDE)

  • Microsoft Visual Studio amb les plantilles d'Acumatica.
  • Acuminator: extensió de Visual Studio per a analitzar i millorar el codi d'Acumatica.
  • Customization Project Editor (dins d'Acumatica) i Git per al control de versions.
  • Cal tenir també IIS i SQL Server per a l'entorn local de desenvolupament.

Exemples de codi

1) Extensió d'un DAC: afegir un camp personalitzat a la comanda de venda.

using PX.Data;
using PX.Objects.SO;

namespace MiProjecte
{
    // Afegeix el camp "Nota interna" a la comanda de venda
    public sealed class SOOrderExt : PXCacheExtension<SOOrder>
    {
        #region UsrNotaInterna
        [PXDBString(255)]
        [PXUIField(DisplayName = "Nota interna")]
        public virtual string UsrNotaInterna { get; set; }
        public abstract class usrNotaInterna : PX.Data.BQL.BqlString.Field<usrNotaInterna> { }
        #endregion
    }
}

2) Extensió d'un Graph (BLC): llançar una regla quan canvia un camp.

using PX.Data;
using PX.Objects.SO;

namespace MiProjecte
{
    public class SOOrderEntryExt : PXGraphExtension<SOOrderEntry>
    {
        // S'executa cada vegada que canvia el client de la comanda
        protected void _(Events.FieldUpdated<SOOrder.customerID> e)
        {
            var order = e.Row as SOOrder;
            if (order == null) return;
            e.Cache.SetValueExt<SOOrderExt.usrNotaInterna>(order, "Revisar condicions de pagament");
        }
    }
}
Els exemples són il·lustratius i estan basats en la documentació oficial del Customization Platform. Cal provar-los en un entorn de demostració abans de presentar-los, perquè els noms de camps i classes poden variar segons la versió.

Acumatica vs NetSuite

La diferència clau és com es paga: NetSuite cobra per usuari, la qual cosa fa pujar el cost a mesura que creix la plantilla, mentre que Acumatica cobra per consum. A més, NetSuite només funciona al núvol d'Oracle i Acumatica permet triar on s'allotja.

Acumatica vs Odoo

Odoo és més barat per a empreses amb pocs usuaris i té una edició gratuïta, i cobreix molts àmbits (web, comerç electrònic, màrqueting). Acumatica sol ser més profund en finances, fabricació i construcció, i resulta competitiu quan hi ha molts usuaris.

Nota: les dades de preus són aproximades i provenen de portals comparatius de tercers, de manera que poden canviar. Indiqueu a la presentació que cal demanar una oferta real.
